# Day322 エラーは成長の証 🐛📚

Python + Streamlit のローカルエラー学習記録アプリです。

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

初回保存時に `data/errors.json` を作成します。データを失わないよう「🛠️ 管理」からバックアップしてください。

## 機能

- エラー登録・分類・全文検索
- 試行錯誤の記録
- 解決済みエラーからの記述式復習クイズと自己評価
- 解決率・時間・自力解決率の分析
- 記録の編集・削除、JSONバックアップと復元

復習クイズは自動採点ではなく、自分の回答と記録した原因を比較する方式です。
